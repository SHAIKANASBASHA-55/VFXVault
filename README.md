## 📖 About

**VFX Vault** is a massive open-source collection of **772+ particle and visual effects** built entirely with **pure HTML5 Canvas and vanilla JavaScript** — zero dependencies, zero frameworks, zero setup.

Every effect is live-previewed in the browser and comes with **copy-ready source code**, making it the ultimate resource for developers, designers, and creators who want stunning visuals without the bloat.

> Press **R** for a random effect. Hours of fun guaranteed 😄

## 🧠 How It Works

Every effect is built using the **HTML5 Canvas API** with vanilla JavaScript:

```
Browser Opens VFX Vault
        ↓
  Browse / Search Effects by Category
        ↓
  Click Any Effect → Live Preview Loads
        ↓
  Canvas API renders particles in real time
        ↓
  Click "Copy Code" → Paste into your project
        ↓
  Press R → Random Effect for discovery
```

No build tools. No bundlers. Open in browser and go.

## ⚡ Getting Started


## 🤝 Contributing

Got a cool effect to add? Contributions are very welcome!

1. Fork the repo
2. Create a new branch (`git checkout -b effect/your-effect-name`)
3. Add your effect inside the right category folder
4. Commit your changes (`git commit -m 'Add: your effect name'`)
5. Push to the branch (`git push origin effect/your-effect-name`)
6. Open a Pull Request

**Guidelines:**
- Pure HTML5 Canvas + Vanilla JS only — no libraries
- Include a working live preview
- Keep code clean and commented
